# P1 Engine (90 min, STRONGEST model). Read ARCH "Engine". Files in `src/engine/`. Vitest, no UI.
Trap: engine must use no window/document/Node APIs (it runs in a worker, vitest, and sim).

## P1a tokenizer + parser + evaluator
Files: `tokenizer.ts`, `parser.ts` (Pratt; exports `parse`, `refsOf`), `evaluator.ts`, `parser.test.ts`, `evaluator.test.ts`.
Tests (one per line): precedence; `2^3^2=64`; `-2^2=4`; parens; `$A$1`==`A1`; range refs expand; range > MAX_RANGE -> #REF!; out-of-grid -> #REF!; x/0; text in arithmetic; empty=0; SUM/AVERAGE/MIN/MAX/COUNT edge cases; unknown fn -> #NAME?; malformed -> {ok:false} never throws; depth>64 and length>1000 guards; error propagation (first error wins).

## P1b Engine class
File: `engine.ts` (+ `graph.test.ts`). Implement exactly as ARCH "Graph": setRaw/link/unlink, loadAll, affected, kahn (head index), tarjanCyclic, recompute (diffed patch + stats), naive mode.
Tests: chain (C1=A1+B1, D1=C1*2); diamond; fan-out; self-cycle; 2-cycle; 3-cycle; downstream-of-cycle shows error; breaking a cycle recovers all; editing an EMPTY cell inside a SUM range updates the SUM; clearing a cell; idempotent setRaw (same raw -> empty patch).

## P1c oracle + bench
Files: `oracle.test.ts`, `bench.ts` (run with tsx).
Oracle: 10,000 random edit sequences over A1:H8 (values, formulas, cycles, clears); after EVERY step, incremental engine state must equal a fresh engine that loaded all raws and ran naive recompute. Seeded PRNG inside the test file only.
Bench: print ms for one edit on (a) 10k fan-out (B1:K1000 = `$A$1*n`), (b) 1,000-deep chain. Record in STATUS.md.
Tag after each step: p1a-green, p1b-green, p1c-green.
